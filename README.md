# Супермаркет Стадикэтс — Black Friday

Мобильная браузерная мини-игра для Telegram в айдентике «История и котики» и «Обществознание и котики».

## Как играть

- 60 секунд смены, 3 жизни.
- На экране появляется заказ котика: история, обществознание или Combo (иногда с другими предметами).
- Тапайте товары на полке, чтобы положить их в корзину, затем нажимайте «Выдать заказ».
- Товары в корзине можно убрать по одному, нажимая на них, либо очистить корзину.
- За точный заказ +100 очков, за несколько предметов +160, серия правильных заказов повышает бонус.
- Ошибка и истёкшее ожидание отнимают жизнь.
- Для победы: минимум 850 очков к концу 60-секундной смены и хотя бы одна жизнь.

## Акция

- −20% на абонементы полугодовых курсов.
- Для второго и последующих предметов Combo скидка 700 ₽/мес вместо обычных 500 ₽/мес.
- Скидки доступны независимо от результата игры.
- Точные условия предложения и сочетание скидок — на сайтах курсов.
- Кнопки уже содержат предоставленные UTM-ссылки на оба сайта.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в его корень `index.html`, `style.css`, `game.js`, а также папку `assets/`.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Ссылку на игру проверьте с телефона, в том числе из Telegram.

Сервер и сборка не требуются. Все игровые данные хранятся только в памяти текущей страницы, без регистрации и персональных данных. Для коммерческого запуска рекомендовано отдельно проверить условия акции, юридические тексты и ссылки.
